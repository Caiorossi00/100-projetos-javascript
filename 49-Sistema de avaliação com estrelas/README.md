Sistema de avaliação com estrelas desenvolvido em JavaScript com manipulação de DOM. A aplicação permite selecionar uma avaliação de 1 a 5 estrelas e exibe a nota escolhida na interface.

A avaliação selecionada é armazenada em uma variável que representa o estado atual do componente. A cada seleção, as estrelas são renderizadas novamente, alternando entre estrelas preenchidas e vazias de acordo com a nota.

O sistema utiliza eventos de clique nos elementos criados dinamicamente para atualizar a avaliação e o resultado apresentado ao usuário.

## MVP

- Exibição de cinco estrelas
- Seleção de uma avaliação
- Armazenamento da avaliação selecionada
- Atualização visual das estrelas
- Exibição da nota selecionada
- Manipulação de eventos de clique
