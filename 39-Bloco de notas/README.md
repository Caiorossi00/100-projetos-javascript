Bloco de notas desenvolvido em JavaScript com manipulação de DOM. A aplicação permite criar notas contendo título e conteúdo, além de editar e remover notas existentes.

As notas são armazenadas em um array de objetos, onde cada objeto representa uma nota. A interface é atualizada após cada operação, permitindo visualizar os dados atuais e realizar alterações em uma nota específica.

A edição utiliza o índice da nota no array para localizar o registro correspondente e atualizar seu conteúdo.

## MVP

- Cadastro de notas
- Entrada de título e conteúdo
- Validação dos campos obrigatórios
- Armazenamento das notas em um array
- Exibição dinâmica das notas
- Edição do conteúdo das notas
- Remoção de notas
- Limpeza dos campos após cadastro
