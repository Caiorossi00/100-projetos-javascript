Rastreador de hábitos desenvolvido em JavaScript com manipulação de DOM. A aplicação permite cadastrar hábitos e controlar se cada hábito foi concluído ou não.

Os dados são armazenados em um array de objetos, onde cada hábito possui um nome e uma propriedade que representa seu estado de conclusão. A interface é atualizada sempre que um hábito é adicionado, concluído, desmarcado ou removido.

O estado de cada hábito é controlado pela propriedade `concluido`, permitindo alternar entre os estados pendente e concluído.

## MVP

- Cadastro de hábitos
- Validação do campo de entrada
- Armazenamento dos hábitos em um array
- Exibição dinâmica dos hábitos
- Marcação de hábito como concluído
- Desmarcação de hábito
- Remoção de hábitos
- Limpeza do campo após cadastro
