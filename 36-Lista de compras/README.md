Lista de compras desenvolvida em JavaScript com manipulação de DOM. A aplicação permite adicionar produtos, marcar itens como comprados e remover produtos da lista.

Os dados são armazenados em um array de objetos, contendo o nome do produto e seu estado de compra. A cada alteração, a lista é renderizada novamente na interface, atualizando a exibição dos itens conforme suas ações.

O estado de cada produto é controlado pela propriedade `comprado`, permitindo alternar entre item pendente e item comprado.

## MVP

- Adição de produtos
- Validação do campo de entrada
- Armazenamento dos produtos em um array
- Exibição dinâmica da lista
- Marcação de produtos como comprados
- Desmarcação de produtos
- Remoção de produtos
