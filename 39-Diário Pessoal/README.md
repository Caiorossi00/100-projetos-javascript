Diário pessoal desenvolvido em JavaScript com manipulação de DOM. A aplicação permite criar entradas contendo título, data e conteúdo, além de remover registros existentes.

As entradas são armazenadas em um array de objetos, onde cada objeto representa um registro do diário. Após cada alteração, as entradas são ordenadas pela data e renderizadas novamente na interface, mantendo os registros mais recentes no início.

O sistema utiliza elementos HTML criados dinamicamente para representar cada entrada e realiza uma validação simples para impedir o cadastro de registros com campos vazios.

## MVP

- Cadastro de entradas
- Entrada de título, data e conteúdo
- Validação dos campos obrigatórios
- Armazenamento das entradas em um array
- Ordenação das entradas por data
- Exibição dinâmica das entradas
- Remoção de entradas
