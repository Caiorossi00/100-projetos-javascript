Lista de contatos desenvolvida em JavaScript com manipulação de DOM. A aplicação permite cadastrar contatos informando nome, telefone e e-mail, além de remover contatos cadastrados.

Os dados são armazenados em um array de objetos, onde cada objeto representa um contato com suas respectivas informações. Após cada alteração, a lista é renderizada novamente na interface para refletir os dados atuais.

O sistema utiliza índices do array para identificar os contatos durante a remoção e realiza uma validação simples para impedir o cadastro de contatos com campos vazios.

## MVP

- Cadastro de contatos
- Entrada de nome, telefone e e-mail
- Validação dos campos obrigatórios
- Armazenamento dos contatos em um array
- Exibição dinâmica dos contatos
- Remoção de contatos
- Limpeza dos campos após cadastro
