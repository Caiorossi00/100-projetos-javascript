Agenda de eventos desenvolvida em JavaScript com manipulação de DOM. A aplicação permite cadastrar eventos informando nome, data e horário, além de remover eventos cadastrados.

Os eventos são armazenados em um array de objetos contendo as informações de cada compromisso. A lista é ordenada cronologicamente utilizando a combinação da data e do horário de cada evento antes de ser renderizada na interface.

O sistema realiza uma validação simples dos campos obrigatórios e utiliza o índice do array para identificar o evento que será removido.

## MVP

- Cadastro de eventos
- Entrada de nome, data e horário
- Validação dos campos obrigatórios
- Armazenamento dos eventos em um array
- Ordenação dos eventos por data e horário
- Exibição dinâmica dos eventos
- Remoção de eventos
- Limpeza dos campos após cadastro
