# Repositório de Prática em JavaScript

Este repositório é dedicado à prática constante de JavaScript por meio de 50 projetos.

Acredito que o desenvolvimento da base de programação deve acontecer principalmente por meio da prática com código. Não é necessário que todo projeto seja grande ou represente uma aplicação completa. Pequenos problemas, desafios e funcionalidades também são capazes de exercitar conceitos importantes quando existe a necessidade de pensar na solução e transformá-la em código.

Foi a partir dessa ideia que este repositório foi estruturado. Os projetos foram pensados para trabalhar diferentes fundamentos de JavaScript em problemas menores e progressivos, permitindo praticar lógica, estruturas de dados, funções, manipulação do DOM, eventos e outros conceitos diretamente na implementação.

As descrições e documentações dos projetos foram elaboradas com auxílio de inteligência artificial. O código foi desenvolvido como exercício de prática, com foco na resolução independente dos problemas, utilizando conhecimento próprio, consulta à documentação e experimentação.

## Sugestões de Prática

- Não utilizar assistentes de IA para programar
- Evitar copiar soluções prontas
- Priorizar a resolução independente dos problemas
- Lidar com um problema ao dia, no ritmo que ficar confortável

## Minha metodologia

Mantive um pequeno caderno com a lista dos problemas e, nos momentos livres, escrevia as soluções no papel antes de passá-las para o computador. A ideia era exercitar a lógica, a estrutura do código e a memória da linguagem sem depender imediatamente do editor ou de ferramentas externas, pensar na resolução de desafios nos momentos livres no dia a dia.

Coding for fun.

## Finalidade

Este repositório funciona como um ambiente pessoal de treinamento para fortalecer os fundamentos de JavaScript por meio de prática deliberada e consistente.

A intenção não é criar aplicações completas ou visualmente elaboradas, mas transformar conceitos da linguagem em código escrito e pensado ativamente.

Mais do que concluir uma lista de projetos, o objetivo é desenvolver maior autonomia para analisar problemas, estruturar soluções e escrever JavaScript sem depender constantemente de ferramentas de inteligência artificial.
