Lista de filmes para assistir desenvolvida em JavaScript com manipulação de DOM. A aplicação permite cadastrar filmes, marcar aqueles que já foram assistidos e remover filmes da lista.

Os dados são armazenados em um array de objetos, onde cada filme possui seu nome e uma propriedade que representa seu status. A interface é atualizada após cada operação para refletir o estado atual da lista.

O status de cada filme é controlado pela propriedade `assistido`, permitindo alternar entre filme pendente e filme já assistido.

## MVP

- Cadastro de filmes
- Validação do campo de entrada
- Armazenamento dos filmes em um array
- Exibição dinâmica da lista
- Marcação de filme como assistido
- Desmarcação de filme
- Remoção de filmes
- Limpeza do campo após cadastro
