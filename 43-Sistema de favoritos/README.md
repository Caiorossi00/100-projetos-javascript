Sistema de favoritos desenvolvido em JavaScript com manipulação de DOM. A aplicação permite cadastrar itens, marcar ou desmarcar itens como favoritos e remover registros da lista.

Os dados são armazenados em um array de objetos, onde cada item possui um nome e uma propriedade que representa seu estado de favorito. A interface apresenta todos os itens e uma lista separada contendo somente aqueles marcados como favoritos.

O estado de cada item é controlado pela propriedade `favorito`. A lista de favoritos é gerada a partir dos itens existentes, sem a necessidade de manter uma segunda estrutura de dados.

## MVP

- Cadastro de itens
- Validação do campo de entrada
- Armazenamento dos itens em um array
- Exibição dinâmica dos itens
- Marcação de item como favorito
- Remoção de item dos favoritos
- Exibição dos itens favoritos
- Remoção de itens
- Limpeza do campo após cadastro
